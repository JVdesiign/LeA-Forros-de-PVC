L&A FORROS — V5.2 GITHUB SAFE

IMPORTANTE: apague os arquivos da versão antiga do repositório antes de enviar esta versão.

1. Baixe e EXTRAIA o ZIP.
2. Entre na pasta extraída.
3. Selecione TODOS os arquivos de dentro dela.
4. No GitHub, abra o repositório LeA-Forros-de-PVC.
5. Apague os arquivos antigos.
6. Envie todos os novos arquivos para a RAIZ do repositório.
7. O index.html deve ficar na mesma tela que v52_logo.webp, v52_loja.webp etc.
8. Faça o commit.
9. Aguarde o Pages terminar o deploy.
10. Abra o site com ?v=52 no final uma vez:
    https://jvdesiign.github.io/LeA-Forros-de-PVC/?v=52

Esta versão usa nomes de arquivos v52_... para impedir que o navegador reutilize imagens antigas em cache.
CSS e JavaScript estão dentro do index.html.
